# 阿药和他的动物朋友们

一款灵感来自《我的世界》的网页版方块生存游戏，使用 Three.js 制作。你可以砍树挖矿、合成工具、建造住处，种植小麦，用熔炉加工材料。世界会昼夜交替，夜里要小心僵尸、骷髅和苦力怕。黄色鸭子阿雏和小小蜥蜴会陪你一起探索。

目前是单人游戏，每位玩家都有自己的世界和存档，暂不支持联机。

## 开始游玩

下载仓库中的 `index.html`，用电脑上的 Chrome 或 Edge 打开，点击“开始冒险”。游戏代码集中在一个 HTML 文件中，无需安装或构建。Three.js 0.180 通过 CDN 加载，打开游戏时需要联网。

进入世界后，点击画面即可用鼠标控制视角；按 Esc 可以释放鼠标。第一次玩可以先收集原木，打开背包制作木板和工作台，再逐步制作工具、收集石头和铁矿。天黑前找个地方搭建庇护所。

## 动物伙伴

阿雏不会受伤或死亡，随身带着一个死亡不掉落的安全箱。喂小麦或种子可以提升好感度：初始容量为 10 格，累计喂食 5 次升到 20 格，15 次升到 30 格。可以直接打开安全箱，也可以在附近放置伙伴箱作为访问入口。

小小蜥蜴会协助战斗。喂肉可以恢复生命、获得经验，升级后增加生命上限，攻击力始终固定为 2。血量耗尽时会进入休养，停止攻击并免疫后续伤害，喂肉恢复后继续战斗。

两位伙伴可以分别召回和召唤，成长状态会保留。跟随时距离过远，会自动传送到玩家附近。

## 保存进度

存档保存在当前浏览器的 localStorage 中，并支持 JSON 导出、导入。安全箱也属于存档，建议定期导出备份。换浏览器、换设备或从本地文件转到网页游玩时，需要手动导入原来的存档；清除浏览器数据可能删除本地进度。

## 部署到 GitHub Pages

将 `index.html` 放在仓库根目录，在 Settings → Pages 中选择 Deploy from a branch，指定 `main` 分支和 `/(root)` 后保存。部署完成后，可通过 Pages 显示的链接访问游戏。具体设置见 [GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
